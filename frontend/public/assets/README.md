# StayCore hospitality imagery

The Home page uses three fixed Unsplash photo assets by URL. They are selected
for hotel and resort context, rather than generated by a random image endpoint.
The URLs are centralized in `src/pages/home/Home.jsx` so approved local assets
can replace them later without changing the layout.

- Hero: `photo-1540541338287-41700207dee6` (luxury resort terrace)
- Reception: `photo-1551882547-ff40c63fe5fa` (hotel interior / reception)
- Room: `photo-1564501049412-61c2a3083791` (hotel room)
